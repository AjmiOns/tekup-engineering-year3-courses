Structure du dossier tp_rag :
- data/ : contient les PDF a indexer
- .env : contient GROQ_API_KEY
- rag_pdf_groq.py : script principal du TP
- requirements.txt : dependances Python

Etapes :
1. Creer et activer un environnement virtuel
2. Installer : pip install -r requirements.txt
3. Remplir le fichier .env avec la cle Groq
4. Lancer : python rag_pdf_groq.py
