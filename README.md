## 📖 Overview

This repository is a structured archive of my work during the **3rd year of the Engineering cycle (Computer Science)**. It gathers, per semester and per subject:

- 📚 **Course material** and summaries
- 🧪 **Labs (TP)** and **tutorials (TD)**
- 📝 **Assignments, quizzes and exam preparation**
- 💻 **Source code** for practical work

The goal is to keep everything **organized, searchable and versioned**, and to make it easy to revisit any topic during revision periods.

> **Note:** all content is shared for educational purposes. Course documents remain the property of their respective authors and institution.

---

## 🗂 Repository structure

```text
tekup-engineering-year3-courses/
├── Semestre 1/
│   └── <Subject>/
│       ├── Cours/        # Lecture notes and summaries
│       ├── TD/           # Tutorials and exercises
│       ├── TP/           # Labs and practical work
│       └── ...
├── Semestre 2/
│   └── <Subject>/
│       └── ...
├── .gitignore
└── README.md
```

Each subject folder follows the same logic so you always know where to look.

## 🚀 Usage

Clone the repository:

```bash
git clone https://github.com/AjmiOns/tekup-engineering-year3-courses.git
cd tekup-engineering-year3-courses
```

Pull the latest updates at any time:

```bash
git pull origin main
```

No installation is required: the repository contains documents and code organized by subject. Individual labs may include their own instructions (dependencies, how to run) inside their folder.

---

## 🧭 Conventions

- **Folders:** one folder per subject, then `Cours`, `TD`, `TP` where applicable
- **Naming:** clear, descriptive file names (e.g. `TP2_Pointeurs.pdf`)
- **Languages:** French for most course material, English for technical documentation
- **Commits:** small and focused, with explicit messages (`Add TP2 – Linux permissions`)
